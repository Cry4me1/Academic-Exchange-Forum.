# 📋 Scholarly 社区公约（行为准则）

**性质**：社区价值观宣言与学术研讨行为准则。

---

## 1. 核心价值观
> **“理性讨论、尊重他人、拒绝人身攻击”**

1. **理性求真**：学术争鸣必须基于实验数据、数学逻辑与客观文献，以理服人。
2. **尊重包容**：尊重跨学科视角与学术探索，鼓励初学者提问，虚心接纳学术批评。
3. **拒绝霸凌**：严厉禁止任何形式的辱骂、贬损、贴标签与网络暴力行为。

---

## 2. 鼓励与倡导（允许什么）
> **“鼓励发布原创观点、学术问题、经验分享”**

1. **原创学术观点**：前沿论文研读笔记、算法构想、开源项目复现心得；
2. **高质量学术求助**：附带清晰背景、最小复现代码或 LaTeX 推导过程的问题探讨；
3. **科研经验分享**：科研避坑指南、学术工具使用技巧、同行评议建议；
4. **建设性互动**：提供有价值的审稿评审反馈、指出论证瑕疵并给出改进路径。

---

## 3. 严格禁止行为（禁止什么）
> **“严禁政治敏感、色情、暴力、广告、版权侵权内容”**

1. **严禁政治敏感与违法信息**：严禁涉政、暴恐、色情、虚假谣言等言论；
2. **严禁商业广告与恶意灌水**：严禁发布推广引流信息、机器人批量刷屏；
3. **严禁学术造假与版权侵权**：严禁抄袭剽窃、严禁上传未经授权的盗版图片/图表；
4. **严禁利用漏洞作弊**：严禁利用技术漏洞刷取信誉分或操纵决斗胜负。

---

## 4. 梯度惩罚机制
> **“第一次警告、第二次删帖、第三次封号”**

| 阶段 | 惩罚动作 | 详细说明 |
| :--- | :--- | :--- |
| **第一次违规** | **系统警告** | 发送站内信警告，说明具体违规条款，扣除违规所获积分并限期整改 |
| **第二次违规** | **下架删帖 / 禁言** | 管理员直接删除违规内容，限制账号发帖与互动 24~72 小时 |
| **第三次违规** | **永久封号** | 永久封禁账号，终止平台所有服务，IP 计入限制黑名单 |
